
# Forge Crystal UI

Copyright © 2026 Boda Chen.

## About

Forge Crystal UI is the original glass-inspired
interface developed for Forge AI Desktop.

Its visual features include:

- Translucent panels
- Dynamic glossy reflections
- Animated progress indicators
- Aqua-blue and scarlet-red effects
- Cursor-reactive lighting
- Layered gradients and backdrop blur

The interface is implemented using HTML, CSS,
and JavaScript.
